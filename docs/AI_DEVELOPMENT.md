# Учёт ИИ-ассистированной разработки

Исходный commit: `30f88274ae4735f3b585934b86d6dc3265d8b5ad`.
Разработка этой ветки выполняется ИИ-ассистентом GPT-6 (идентичность из системного
контекста; точный идентификатор варианта модели не предоставлен). Нельзя подменять
это поле предполагаемой версией модели или выдавать генерации за независимый review.

Для каждой исследуемой задачи сохраняются: ID требования, исходный commit, дата,
модель, полный запрос, исходный patch, SHA-256 patch, ручные исправления, итоговый
commit и ссылки на машинные отчёты. Исходный patch после генерации не переписывается.
Результаты исправленной версии учитываются отдельно от исходного ИИ-ответа.

`experiments/ai_changes.csv` — индекс происхождения. Пустое поле результата означает
«не выполнено», а не успешную проверку. `pending_review` исключается из расчёта
чувствительности и ложных отклонений, но не из учёта времени и инфраструктурных сбоев.

## Независимая оценка

Оценщик сначала читает требование и patch без результатов A/B/C, определяет
`correct`, `defective` или `uncertain`, записывает сценарий воспроизведения и своё имя.
После этого открываются результаты конвейеров. Исходную метку и последующие
исправления хранить раздельно. Разногласия явно сохранять; результат самого C не
является эталонной разметкой.

Новые ИИ-задачи корпуса генерируются отдельно от изменений основного продукта.
Генерации в одной беседе не являются независимыми выборками разных моделей;
это ограничение должно быть отражено в ВКР. Нельзя выдумывать историю запросов,
ручные исправления, оценки человека, затраты API или отсутствующие прогоны.
